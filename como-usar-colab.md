# Como utilizar os laboratórios no Google Colab

Cada laboratório contém exemplos de Python para executar, alterações para experimentar e cinco questões de reflexão. Trabalha numa cópia pessoal. Não é necessário escrever respostas no notebook nem enviá-las ao professor.

## Abrir um laboratório

1. No [índice das aulas](https://github.com/agoncalveslx-gif/Programacao), escolhe o tema e carrega no botão **Abrir no Colab**.
2. Inicia sessão na tua conta Google, se necessário.
3. No Colab, escolhe **Ficheiro / File → Guardar uma cópia no Drive / Save a copy in Drive**.
4. Dá à cópia um nome que identifique a aula, por exemplo `03-selecao-i-meu-laboratorio`.
5. Executa e altera o código na tua cópia pessoal.

### Alternativa por descarregamento

Se preferires, abre a ligação **Notebook** do tema no GitHub e descarrega `laboratorio.ipynb` com **Download raw file**. Depois abre o [Google Colab](https://colab.research.google.com/), escolhe **Ficheiro / File → Carregar notebook / Upload notebook** e seleciona o ficheiro.


## Executar e experimentar

- Lê a explicação e prevê o resultado antes de executar.
- Executa uma célula com o botão triangular ou com **Shift+Enter**.
- Faz as alterações nas células indicadas e volta a executá-las.
- Quando surgir um pedido de entrada, escreve o valor e confirma com Enter.
- Executa as células por ordem. Se reiniciares o ambiente, volta a executar as definições e os dados de que precisas.
- Consulta `laboratorio-solucoes.pdf` na pasta da aula depois de tentares realizar o laboratório.

Os ficheiros criados durante a execução ficam no ambiente temporário do Colab. Descarrega aqueles que pretendas conservar.

Referência: [FAQ oficial do Google Colab](https://research.google.com/colaboratory/faq.html).
